## Решения

**Статусы.** «Предстоящие» — `scheduled`, `live`, `postponed`: матч ещё будет сыгран или доигран, результат не окончательный. «Завершённые» — `finished` и `cancelled`: больше не изменятся. Неизвестный статус не угадываю — такой матч виден только во «Все» с подписью «Статус: <значение>». Категорию определяю по статусу, а не по дате: в данных `scheduled`-матчи уже в прошлом, дата ненадёжна.

**Неочевидные случаи в данных:**
- `score: {0, 0}` у m2 — проверка `score ? …` на числах потеряла бы 0:0; проверяю типы полей, а в карточке — объект на `null`.
- `startsAt: null` у перенесённого m7 — `new Date(null)` дал бы 1 января 1970; показываю «Дата пока не назначена». Невалидная строка даты тоже становится `null`.
- `live` с полем `minute` — показываю «Идёт · 67′»; проверка `minute !== null`, чтобы не терять 0-ю минуту.
- Ответ валидируется: битый матч пропускается (с `console.warn`), а не роняет весь список; неверный формат ответа и не-2xx статус — ошибка.
- Время — через `Intl.DateTimeFormat` без `timeZone`, т.е. в поясе устройства.
- Если обновление упало, уже загруженный список не пропадает — сверху показывается баннер с ошибкой. Старый запрос отменяется `AbortController`, чтобы его ответ не перетёр новый.

## Баги из части 2

1. **Звёздочки.** `Boolean(favorites.indexOf(id))`: для отсутствующего id `indexOf` возвращает `-1`, а `Boolean(-1) === true` — поэтому горели все звёзды; у первого избранного индекс `0` → `false`, и он гас. Кроме того, `toggle` мутировал массив state и передавал в `setFavorites` ту же ссылку — React сравнивает по ссылке и перерисовку пропускал, изменение «всплывало» при случайном следующем рендере. Исправил: `includes` и функциональное обновление, которое возвращает новый массив.
2. **«Обновлено N сек назад».** Колбэк `setInterval` замкнул `seconds` из первого рендера (0), поэтому каждую секунду ставил `0 + 1` — число застывало на 1. Проп `since` вообще не использовался, поэтому после обновления ничего не сбрасывалось; интервал ещё и не очищался. Исправил: секунды считаются из `Date.now() - since` на каждом рендере, интервал лишь перерисовывает компонент и очищается в cleanup; экран передаёт новый `Date` после каждой успешной загрузки.

## Как я использовал ИИ

Claude Code (агент) — разбор кода, реализация, коммиты; результат проверял чтением диффов, `npx tsc --noEmit` и запуском в браузере. Где ИИ ошибался:
- Первый черновик объяснял баг звёздочек только индексом `0` и пропускал главное — `Boolean(-1) === true`, из-за которого горят все звёзды. Заметил, сверив объяснение с жалобой тестировщика.
- Черновик полагался только на pull-to-refresh — в браузере он не работает, обновить данные в `npm run web` было нельзя. Добавил явную кнопку.
- Агент сообщил, что `npm install` прошёл, хотя он упал по сети: код выхода был от `echo` в той же команде. Заметил по пустому `node_modules`.
